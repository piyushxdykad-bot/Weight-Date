# The Weight Date — concept website

Concept website for **The Weight Date** gym, Prayagraj — one membership, two branches (Tagore Town · Civil Lines).

**Scroll-video website:** `site/` — **Sections:** scroll-scrubbed 192-frame video hero · About · Facilities (stacked cards) · Programs · Program finder (BMI, Asian-Indian cut-offs) · Trainers · Membership · Transformation gauge + medal wall · Google reviews · Horizontal gallery · Nutrition · Booking form (to WhatsApp) · Branches · Final CTA.

**Stack:** plain HTML/CSS/JS, GSAP + ScrollTrigger, Lenis smooth scroll. No build step — open `index.html` or serve the folder.

```
npx serve .
```

**Main page — web app (landing + app):** root `index.html` — landing-style home with video hero, working programs finder, plans, slot booking, coaches, branches, plus member and trainer dashboards after login (demo code 1234).

**Member app demo:** `app/` — member + trainer views (OTP login demo code 1234), trainer-set workouts and diet, goals, slot booking, membership. Sample data saved in the browser.

Imagery and hero video generated with Google Flow (AI). Prices on the page are samples.
