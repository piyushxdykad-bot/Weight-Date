# The Weight Date — concept website

Concept website for **The Weight Date** gym, Prayagraj — one membership, two branches (Tagore Town · Civil Lines).

**Sections:** scroll-scrubbed 192-frame video hero · About · Facilities (stacked cards) · Programs · Program finder (BMI, Asian-Indian cut-offs) · Trainers · Membership · Transformation gauge + medal wall · Google reviews · Horizontal gallery · Nutrition · Booking form (to WhatsApp) · Branches · Final CTA.

**Stack:** plain HTML/CSS/JS, GSAP + ScrollTrigger, Lenis smooth scroll. No build step — open `index.html` or serve the folder.

```
npx serve .
```

**Member app demo:** `app/` — member + trainer views (OTP login demo code 1234), trainer-set workouts and diet, goals, slot booking, membership. Sample data saved in the browser.

Imagery and hero video generated with Google Flow (AI). Prices on the page are samples.
